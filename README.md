# 《宋池1057》

—— 苦瓜木鱼蛤蟆

引言

北宋很富——富到此后千年间，史书中反复称颂的那些”盛世”，论起寻常日子的实在与滋润，未必比得上北宋百姓的日常。

北宋很稳——稳到纵观上下千年，再难找出第二个朝代，能像北宋这样，几乎不见大规模的战乱，不见频发的灾荒，也不见成气候的叛军揭竿而起。

北宋的文坛很奔放，诗词歌赋，几乎把华夏文学推上了顶峰。

北宋的商业也很自由，沿街的住户可以自行开窗行商，都城里夜市灯舫，彻夜通明。

可是，宋并不弱。

它只是，很窝囊。

当年，太祖赵匡胤白袍白马，仗一根盘龙棍，走出汴京，一路横扫四方；等他再回来时，已经黄袍加身，跨着赤色骏马，定都开封，开创了这个王朝。也正因这段”马上得天下”的经历太过深刻，终宋一朝，都在小心翼翼地提防武将手握重兵——生怕陈桥旧事，重演在别人身上。于是，天下最精锐的禁军，大多常年驻扎在都城左右，养尊处优；素有武曲之称的狄青，纵有平定侬智高之乱的赫赫战功，官至枢密使，最终也难逃朝堂的猜忌，郁郁而终，终究只能镇守一方，难有真正开疆拓土之战；范仲淹这样的文臣，唯有边事告急、西夏兵锋逼近时，才会临危受命，挂帅出征；就连少年时”喜谈兵”、一心想组织义军收复失地的张载，也在拜见范仲淹时，被一句”儒者自有名教可乐，何事于兵”的劝诫点醒，最终弃武从文，把一腔血气，收敛进了经史子集之中，养成了日后那副中庸沉静的性子。
而章衡——这个文能安邦、箭能定军魂，心中始终存着收复燕云十六州之志的人——从他踏入这个时代的那一刻起，便注定无法在边关军事上，掀起哪怕一丝真正的波澜。

他生活在科举最为辉煌的时代，却并不认为科举是选拔人才最好的方式——然而偏偏是这样一个对制度心存疑虑的人，最终被这套制度选中，成为嘉祐二年那一榜的榜首。
那一年，天下士子云集汴京。那一榜，后来被称为北宋乃至华夏几千年科举史上最耀眼的一榜。

虽然他曾站在这群星闪耀的最高处，也在此后的四十年中纵横官场，历史却是如此奇妙——在后世史书中却未能留下与他的才华相称的篇幅；一个半生致力于修订、整理史书的人，最后却仿佛被史书本身悄然遗落。
关于他的生平，我们今天能够找到的，不过是散落在正史、笔记、诗文、墓志、地方志以及后世族谱中的只言片语。一段关于少年时代的记载，一句关于仕途的感叹，一篇与友人的唱和，一次面对权臣时的抗争，一场出使辽国时令人惊叹的射礼，还有一个又一个被后人轻轻带过的名字。

这些文字彼此相隔数十年，像散落在时间长河中的石块。我希望能一点一点拾起它们，辨认上面的刻痕，再试着把它们重新拼接起来——尽管我们永远无法拼出一卷完整的书。

有些地方，史料会告诉我们事实；有些地方，史料只留下模糊的轮廓；还有一些地方，历史永远沉默。
所以这并不是一本把所有空白都填满的传记。
它更像是一幅写意的长卷。

我们试图沿着章衡留下的足迹，从浦城的山水开始，走进他的少年时代；从他的家庭与师友开始，走进北宋士人的精神世界；从嘉祐二年的科举风云开始，走进那个群星璀璨的时代；再一路走到汴京的宫阙、地方的州县、辽国的风雪，以及北宋政治最激烈的漩涡之中。
而在这条道路上，我们也将遇见苏轼、苏辙、曾巩、章惇、陈襄，以及那个时代无数后来改变中国历史的人。

他们年轻的时候，也曾经只是一个个意气风发的少年。有人出生于名门，有人来自寒门；有人自幼便拥有通往汴京的道路，有人需要翻山越岭才能走出故乡；有人最终成为宰执，有人名留千古，有人沉入历史深处，再无人问津。
而决定这份殊途的，往往还不只是他们自己，更是各自的父亲。

章惇的爹，年轻时风流成性，后世笔记里甚至留下一种说法——说他是这位爹与丈母娘私通所生。真假难辨，却也足够惊世骇俗。

苏洵二十七岁才想起读书这回事，此前半生游荡不定，两个儿子的开蒙，靠的是家里那位一个人撑起布号与谷田的母亲。

曾巩的爹，本是官宦门第，中年丢官，家道中落，没几年便撒手人寰，留下九个妹妹、四个弟弟，还有一个尚未考中进士的长子——曾巩替父亲还了十年的债，不是钱债，是把这些弟妹一个个抚养、教书、嫁娶的责任。

张载的爹，死在千里之外的涪州任上。十五岁的儿子扶着灵柩，翻山越岭，走到半路盘缠用尽，只能就地安葬，从此再没能回到故乡开封。

章衡的爹——他的故事，本书稍后会细讲。此刻只需知道：这个孩子年少时随父亲四处漂泊，直到快二十岁，才被送回浦城老家读书。

这些爹，没有一个称得上”靠谱”。

有的荒唐，有的窘迫，有的早逝，有的干脆把儿子丢在半道上。可正是这些残缺、错位、甚至有些荒诞的父辈，用各自的方式缺席了儿子的成长——却也因此，把一群少年，各自推到了不得不自己往前走的位置上。
三十多年后，他们几乎在同一年，站到了同一张考卷前面。
他们共同生活在一个极其特殊的时代。那是北宋最灿烂的年代之一。商业、城市、教育、科举、文学、史学与政治彼此交织，汴京成为天下文明汇聚之地，而一个来自闽北浦城的少年，也在群山之间慢慢抬起头来。
他看见远山。

于是问：
“山那边有什么？”

后来，他真的走了出去。他走过山川，走过州县，走进汴京，走上殿试金榜；他做过地方官，也进入过中央；他面对过百姓的疾苦，也面对过庙堂的权力；他曾经以文章立身，也曾经以弓箭震慑辽廷；他参与政治，也参与史学。
他的一生，远比”状元”二字更加辽阔。

可是千年之后，当我们重新寻找他时，却发现这个人的身影已经越来越淡。

于是，我想重新把他写出来。不是为了给他增加一个虚假的传奇，而是想从那些真实留下来的文字里，重施笔墨，把一个曾经真实存在过的人，重新写回世间。

如果史料能够告诉我们”这是事实”，我便尊重事实。

如果史料只留下疑问，我便留下猜想。

如果历史沉默无言，我才允许文学在沉默的边缘轻轻补上一笔。

因为我最终想寻找的，并不仅仅是一个状元。

我想寻找的，是一个人。

一个从浦城走出来的少年。

一个曾经相信自己能够看见天下的人。

一个在最辉煌的科举时代被科举选中的人。

一个半生整理史书、最终却只被史书留下寥寥数笔的人。

也是一个在千年之后，仍然值得我们重新认识的人。

他小时候问山那边有什么。

后来走了一生，终于走到了天下。

而这本书，便从他回望那座山的地方开始。

科举历千年，嘉祐压群榜。
